# Say the word on beat

Spel met eigen afbeeldingen, meerdere thema’s en een achtergrondtrack op standaard 72 BPM.

## Online openen

Ga naar **Settings → Pages** en kies **Deploy from a branch**, branch **main**, map **/(root)**. Klik **Save**.

Het spel verschijnt daarna op https://hobbit12b.github.io/rappen/ (publicatie kan enkele minuten duren).

Foto’s, eigen audiobestanden en thema’s worden alleen in de browser op je apparaat opgeslagen. Ze worden niet naar deze repository gestuurd.

De standaard hip-hoptrack is aangeleverd door de opdrachtgever. Gebruik de track volgens de voorwaarden van de oorspronkelijke maker.
